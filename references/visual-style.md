# 三色黑墨金赭肖像视觉规范（v8 定稿）

本规范依据用户认可的成品 `assets/style-anchor-v8.png` 提取，是该技能的唯一画风标准。旧版 8 张参考已归档到 `assets/archive-original/`，不再使用。

## 一句话定义

不是水彩淡彩，是**三色高对比插画**：纯白纸 + 纯黑墨线 + 平涂金赭。色数砍到三色，线条粗细拉到统一，靠留白和线条结构说话。

## 配色：只有三色

| 角色 | 色值 | 用法 |
|---|---|---|
| 纸白 | `#FFFFFF`（可带极淡暖调） | 背景、面部主体、衣服、眼白、镜片 |
| 墨黑 | `#111110` | 全部线条、小面积实黑 |
| 金赭 | `#C9A24A` | 只做结构阴影与头发暗部 |

**禁止**：中间灰、肤色渐变、藏青、褐色、任何第四种颜色。

## 构图

- 2:3 竖幅，单人居中，紧裁头肩像。
- 头部高度占画幅 60%–65%，脸要画大。
- 肩膀切在画幅下边缘，**不画手臂和躯干**。
- 背景纯白平面：无纸纹、无颗粒、无渐变、无暗角、无投影。

## 线条

- 全画以中等粗细为主，粗细基本统一。
- 同一根线最粗处不超过最细处的两倍。
- **禁止**墨块状、排笔状、坨成一团的粗黑笔画。
- 实黑只用于小面积：眼镜框、眉毛、耳窝、鼻孔、唇缝。
- 皱纹、眼睑、唇线、鼻翼用细线，但不能细到发丝。

## 金赭

- 平涂、饱和、边缘锐利，像丝网印；无渐变，与纯白之间界线明确。
- 位置**仅限**：头发暗部与发流转折、太阳穴与额头侧边、颧骨、鼻梁一侧、颈部成块、耳前。
- 面部大面积保持纯白。
- **零金色区**：上唇上方、人中、下巴、下颌线、衣服。

## 头发

- 用 4–6 组发束表现，**不要点阵、不要贴片、不要硬边色块**。
- 中等粗黑线勾发束边界，线条有长短、有断开，不画成一圈连续轮廓。
- 发束内部大量留白。
- 暗部与转折处平涂金赭。
- 发梢用长短不一的细黑线收尾，自然化进纸白，不留硬边。
- 分缝处一条细线；鬓角一小块实黑压重量。

## 面部

- 大面积纯白，只保留必要的结构线。
- 眼白纯白，虹膜细黑圆环，瞳孔实黑，上眼睑一条中等黑线。
- 眼镜：黑实心矩形框，粗细适中、转角干净，镜片纯白无反光。
- 下颌只用一条细黑线交代，不加阴影。

## 衣服：纯线条，绝不上色

- 全部纯白 + 黑线：零填色、零金色、零灰调、零深色块。
- T 恤与外套靠线条结构区分：T 恤一个圆领弧线；外套帽沿弧线 + 两根抽绳 + 两条开襟长线 + 几道褶线。
- 需要一点重量时只用 3–5 道稀疏平行细线，绝不能变成涂色块。
- 衣服线宽与脸部轮廓一致，不加粗。

## 不要胡须

- 不画胡须、胡子、胡渣、上唇阴影、下巴阴影、下颌一圈深色带。
- 上唇上方、人中、下巴、下颌线全部纯白。

## 偏差与修正

| 偏差 | 修正 |
|---|---|
| 出现中间灰、肤色渐变 | 砍回三色，阴影只许用金赭平涂 |
| 线条过粗、出现墨块 | 统一到中等粗细，最粗≤最细×2，实黑只留小面积 |
| 上唇或下颌有金色、看着像胡子 | 上唇、人中、下巴、下颌线清零，金色只留太阳穴/颧骨/鼻侧/颈部/耳前 |
| 头发成点阵或贴片 | 改成 4–6 组发束轮廓，内部留白，暗部平涂金，发梢打碎 |
| 衣服被填色（尤其深色 T 恤、黄色雨衣） | 衣服清零填色，只留线条；黄色雨衣不要用金色表现 |
| 画成半身像、头太小 | 紧裁头肩像，头占 60%–65%，不画手臂躯干 |
| 背景有纸纹、颗粒、暗角 | 纯白平面，去掉一切纹理 |
| 人物变年轻、变瘦 | 以原照片为准，脸型、下颌、年龄不许美化 |

## 验收清单

1. 只有三种颜色，没有灰调。
2. 线条粗细统一，没有墨块。
3. 上唇、人中、下巴、下颌线纯白，不像有胡子。
4. 头发是发束结构，不是点阵贴片。
5. 衣服只有线条，没有任何填色。
6. 紧裁头肩像，头占画幅 60%–65%，背景纯白无纹理。
7. 一眼能认出源人物，年龄、脸型、眼镜、表情一致。
